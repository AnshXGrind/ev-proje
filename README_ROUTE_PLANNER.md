# India-wide Route Planner

GRIDPULSE reviews a selected driving route against the available charger inventory, sampled elevation and explicit coverage-spacing scenarios. It is a preliminary planning screen, not a traffic forecast, electrical power-flow study, or proof of regulatory compliance.

## Run on Windows

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-mvp.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Open `http://127.0.0.1:8000/route-planner`.

## What it supports

- The full national state/UT list.
- Place search and manual coordinates, with coordinates rejected when they fall outside the locally installed India boundary polygons.
- Nationwide charger inventory, pre-filtered against the same polygons used by the dashboard.
- Route geometry, distance, duration, elevation sampling and terrain screening.
- General public-charger reference spacing and fast-charge review spacing, kept separate from more conservative scenario-based spacing.
- Optional illustrative charging-session and energy scenarios when user-provided traffic and EV-share assumptions are supplied.
- Candidate charging coordinates that are skipped if their point falls outside the India boundary union.

The boundary file is generated by `scripts/validate_india_inventory.py` from the NIC WebGIS state/UT layer. The planner fails closed in nationwide mode if the boundary file is missing or cannot be normalized.

## Limitations

The BEE inventory is a snapshot dated 2025-10-26, not a live status feed. Candidate locations are unverified for land access, road-entry permissions, exact site suitability, flood/seasonal risk, grid capacity, permits and capex. Route-spacing and demand values use declared assumptions and are not fitted to measured charging outcomes. Public routing, geocoding and elevation services are best-effort dependencies.
